# 版权与公开边界

本项目是粉丝向制作方法分享，不是官方授权素材库。

## 仓库适合公开
- 自己写的教程
- 工程尺寸
- 拼版/QC方法
- AI工作流与提示词
- 自己原创的模板元素
- 经确认可公开的实物制作照片

## 不默认打包公开
- 动画/漫画/游戏官方原图全集
- 他人插画师作品原文件
- 未获许可的高清素材包
- 付费素材
- 可替代原作品消费的内容

## 成品案例

如果案例使用第三方作品元素，公开前应单独判断展示范围、来源和许可。仓库中的“制作方法可公开”不代表其中每一张第三方图片都自动拥有再分发权。

《凡人修仙传》及相关名称、角色和官方视觉资产的权利归相应权利人所有。
