# 最终交付清单｜V0.3 RC

## 给另一位制作者时

只需要分享本 GitHub 仓库地址。

他不需要：
- 原项目聊天记录；
- 原作者的完整素材库；
- 原始漫展交换卡库存；
- 重新研究尺寸和出血。

他需要：
- 自己要制作的主题；
- 自己可使用/参考的图片；
- 一个能读取本仓库和图片的 AI；
- 第一次黄金样卡的人工确认。

## AI 应能从仓库找到

- [x] 主 Skill
- [x] 63×88 mm工程规格
- [x] 3 mm出血
- [x] 正反面统一规则
- [x] 平面出框/裸眼3D原则
- [x] A4 2×4双面拼版方法
- [x] 印刷/成本经验
- [x] QC
- [x] 漫展实战反馈
- [x] 版权边界
- [x] 已完成案例索引
- [x] 可复制的AI启动指令

## 一套新卡的最终文件

建议至少保留：
1. 黄金正面母图
2. 统一背面母图
3. 每张单卡打印母图
4. A4双面TEST拼版
5. 实物测试结果
6. A4双面FINAL拼版
7. QC记录

## 正式印刷门槛

只有：
- 单卡QC PASS；
- 正反方向实物测试 PASS；
- 裁切/对位 PASS；
- 实际字号 PASS；
- 纸张/覆膜确认；

才标记 **PRINT READY**。
