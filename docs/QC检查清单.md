# 小卡印前 QC 检查清单

## 单卡
- [ ] 成品尺寸63×88 mm
- [ ] 四边3 mm出血
- [ ] 重要文字不在裁切危险区
- [ ] 主体关键部位未被裁切
- [ ] 图片没有被拉伸变形
- [ ] 实际尺寸下文字可读
- [ ] 出框效果没有破坏主体识别
- [ ] 外框与系列其他卡一致

## 背面
- [ ] 与正面成品框一致
- [ ] 统一背面版本正确
- [ ] 正文/说明实际尺寸可读
- [ ] 无旧版本残留

## 拼版
- [ ] A4 2×4布局正确
- [ ] 卡间距/外框一致
- [ ] 正反数量一一对应
- [ ] 双面翻转方向已用实物测试确认
- [ ] 裁切后正背没有明显错位

## 印刷
- [ ] 纸张/覆膜与订单一致
- [ ] 已先做小样
- [ ] 深色区域没有糊死
- [ ] 细字没有消失
- [ ] 覆膜后对比度可接受
- [ ] 裁切误差可接受

全部 PASS 后才能标记 PRINT READY。
