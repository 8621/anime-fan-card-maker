# 正反面与系列统一规则

## 1. 先做系列，不做“每张一套风格”

漫展交换卡拿在一起时，系列识别非常重要。

固定层建议包括：
- 卡片外框
- 左上信息区
- 中下文字区
- 字体层级
- 背面
- 裁切/出血基准

变量层：
- 角色/法宝主体
- 名称
- 与该卡对应的短文字
- 背景和局部特效

## 2. 正面

主体优先。角色、法宝或核心视觉应在63×88 mm实际尺寸仍能第一眼识别。

“出框”允许主体局部跨过内框，但不能跨到危险裁切区域，也不能为了效果切掉最关键的识别部位。

## 3. 背面

原项目采用粉丝向统一背面。统一背面的价值：
- 一眼知道属于同一系列；
- 交换时更像完整收藏物；
- 批量拼版更稳定；
- 不需要每张额外设计一套背面。

背面文字实际打印前必须检查字号。屏幕放大看着舒服，不代表63×88 mm成品可读。

## 4. 文字层级

原项目验证过“重点词放大”和背面正文重新排布的思路。

规则：
- 重点词可以放大，但数量要受控；
- 文字不能压住主体关键区域；
- 小卡不是海报，文字越多越需要实际尺寸测试；
- 如果正文太长，优先删减/重排，不无限缩小字号。

## 5. 版本命名

推荐保留明确版本：
`主题_正面_V1.png`
`主题_背面_V1.png`
`主题_A4_2x4_双面_TEST.pdf`

通过实物测试后再标 FINAL。不要用“最终版2、真的最终版3”这种无法追踪的命名。
