# A4 2×4 双面拼版规则

> 原项目已有实际测试拼版通过的案例。本文件锁定工作方法；具体打印机的双面翻转方向仍必须通过小样确认。

## 标准流程

1. 单卡正面 FINAL 候选
2. 单卡背面 FINAL 候选
3. 确认63×88 mm成品框与3 mm出血
4. 建立 A4 2×4 测试拼版
5. 检查卡与卡之间的裁切空间/外框
6. 生成正面页
7. 按实际打印翻转逻辑生成背面页
8. 打印测试
9. 对光/裁切检查正背对位
10. PASS 后才批量印刷

## 为什么必须测试双面

不同打印机/商家可能使用：
- 长边翻转
- 短边翻转
- 不同进纸方向

所以不能只靠屏幕判断背面应该“镜像还是旋转”。第一次必须做实体双面测试。

## 原项目验证点

V01 测试拼版最终特别处理过：
- 左右间距
- 外框统一
- A4 2×4
- 双面关系

说明拼版不是简单把8张图平均塞进A4；卡间距、外框和正背对位都属于工程的一部分。

## 输出纪律

A4拼版是**打印派生文件**，不是设计母版。

以后修改卡面，应回到单卡母图修改，再重新派生拼版；不要直接在A4 PDF上修某一张卡。
