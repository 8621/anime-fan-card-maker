# 漫展实战反馈｜交换物料真正怎么用

## 真实使用结果

原项目曾为漫展准备约60张粉丝向小卡，现场交换后基本换完。

这个结果至少说明：
- 63×88 mm卡片适合携带和现场交换；
- 经济纸材路线足以承担大量交换用途；
- 系列化卡面具有实际交流/收藏价值；
- 第一次项目没有必要一开始就上昂贵特殊工艺。

## 从同行物料得到的启发

漫展现场会同时出现卡片、异形物料、贴纸等不同形式。对本项目来说，最值得保留的不是无限扩品类，而是：

1. 主卡系列保持统一；
2. 让主体第一眼可识别；
3. 正反面都像“成品”，不是只有正面好看；
4. 控制成本，让制作者愿意真正拿出去交换；
5. 用少量特色卡制造记忆点，而不是每张都堆工艺。

## 成本与交换心理

如果单张成本过高，制作者会天然舍不得大量交换。300g铜版纸覆膜的经济路线因此具有实际优势。

特殊纸、彩闪等可以以后作为少量特别版，而不是默认基础版。

## 项目暂停时的经验

当短期没有下一场漫展时，不必为了“保持更新”持续扩卡、重做旧卡或增加赠品。

已经验证的主卡体系应冻结保存。下一次活动再根据主题和交换需求扩展。

这也是本 Skill 的原则：**真实需求驱动生产，而不是为了填项目而制造库存。**
