# 《凡人修仙传》同人小卡制作指南｜AI Fan Card Maker

> 从一张喜欢的角色/法宝图片出发，在 AI 辅助下完成 **63×88 mm 同人收藏小卡 → 正反面 → 出框/裸眼3D视觉 → 3 mm出血 → A4双面拼版 → 实体印刷**。

## 项目从哪里来

这套流程来自一次真实的《凡人修仙传》粉丝物料制作与漫展交换实践。项目制作过多张法宝/主题卡，并完成了实体印刷、双面拼版和现场交换验证。

它不是“万能自动画卡工具”，而是一套把已经踩过的坑、尺寸、印刷和 AI 协作方法整理出来的制作指南。

## 已验证规格

- 成品尺寸：**63 × 88 mm**
- 四边出血：**3 mm**
- 推荐经济印刷：**300g 铜版纸覆膜**
- 已验证测试拼版：**A4 / 2×4 / 双面**
- 裸眼3D/出框：通过**平面视觉设计**实现，不依赖特殊立体印刷工艺
- 正反面：统一尺寸、统一外框、统一双面对位逻辑

## 目标用户

适合：
- 想做《凡人修仙传》粉丝小卡的人
- 第一次给漫展准备交换物料的人
- 想让 AI 帮忙做卡面，但不知道怎么给尺寸/印刷要求的人
- 想把同样流程迁移到其他动漫/游戏同人卡的人
