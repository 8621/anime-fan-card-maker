> 一套经过真实制作、实体印刷和漫展交换验证的 AI 辅助同人小卡工作流。

**主题 → 黄金卡面 → 统一背面 → 出框/裸眼3D视觉 → 63×88 mm → 3 mm出血 → A4 2×4双面拼版 → 小样 → QC → 正式印刷**

## 🚀 第一次使用

不需要先研究整个仓库。

1. 打开 [START_HERE.md](START_HERE.md)
2. 准备角色/法宝/主题和参考图
3. 把本仓库交给支持文件读取的 AI
4. 让 AI 先读 [skill/SKILL.md](skill/SKILL.md)
5. 复制 [AI制卡启动指令](templates/AI制卡启动指令.md)
6. **先做1张黄金样卡，PASS 后才批量**

## 为什么不直接“让AI随便画一套”

小卡真正困难的不是生成一张漂亮图片，而是：
- 63×88 mm实际尺寸仍然清楚；
- 系列放在一起统一；
- 主体不被文字和出框效果破坏；
- 正反面对得上；
- 有正确出血；
- 拼版能打印；
- 裁切后仍然成立。

所以本项目把“好看的图”和“能印出来的小卡”分开处理。

## 漫展实战

原项目曾准备约60张粉丝向小卡用于漫展交换，现场基本交换完。这也是为什么本仓库更重视：

**系列感、可交换性、成本、实体效果**

而不是单纯追求昂贵工艺。特殊纸/彩闪可以作为少量特别版，基础系列优先保证稳定和愿意交换。
