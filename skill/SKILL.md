# SKILL.md｜《凡人修仙传》同人小卡制作 Skill

> 版本：V0.1

## 1. 使命

帮助用户在 AI 辅助下完成可实际印刷的粉丝向收藏小卡。默认成品为 63×88 mm，并建立统一正面、统一背面、出血、拼版和 QC 流程。

## 2. 固定工程参数

- 成品：63×88 mm
- 出血：四边3 mm
- 带出血设计尺寸：69×94 mm
- 双面卡必须共享相同成品尺寸和裁切基准
- 默认先单卡定稿，再进行A4拼版

## 3. 状态机

### S0 INPUT
接收主题、参考图和用户文字。

### S1 ASSET_CHECK
确认素材是否清晰、主体是否适合竖卡、是否存在明显来源/授权风险。未知来源不得描述成“官方授权”。

### S2 GOLDEN_FRONT
先完成一张黄金正面。统一左上/中下文字体系，背景保留主体视觉。

### S3 GOLDEN_BACK
确定统一背面。背面应能让整套卡形成系列识别，不逐卡重新设计。

### S4 EFFECT_CHECK
检查出框/裸眼3D视觉。这里指平面构图产生的层次错觉，不虚构特殊印刷工艺。

### S5 PRINT_CHECK
检查63×88成品框、3mm出血、安全区、清晰度、文字和主体是否被裁切。

### S6 BATCH
黄金正背面 PASS 后才能批量制作。批量页只替换允许变化的内容。

### S7 IMPOSITION
按锁定规则生成 A4 2×4 双面拼版，检查正背方向和对位。

### S8 PROOF
先打小样。观察颜色、覆膜、裁切、正反对位和文字可读性。

### S9 PRINT_READY
QC 全部 PASS 后才标记正式印刷版。

## 4. 设计原则

- 主题主体优先，不能被文字或效果遮死。
- 系列卡统一比单张“每张都很炫”更重要。
- 出框效果服务主体，不为了3D感强行切掉关键部位。
- 小卡实际尺寸很小，屏幕放大可读不代表打印后可读。
- 文字区域必须保持统一位置和层级。
- 背面优先统一，形成交换/收藏时的系列感。

## 5. 禁止

- 不把 AI 图冒充官方原画。
- 不把第三方素材库直接重新打包公开。
- 不因一张卡异常重做已经 PASS 的全部卡。
- 不在未确认成品框/出血前批量制作。
- 不用A4拼版文件反向当作单卡母版。
- 不未经实物小样就声称“印刷一定没问题”。

## 6. 完成定义

最终至少交付：
- 单卡正面打印母图
- 统一背面打印母图
- 带3mm出血的印刷文件
- A4双面拼版
- QC结果
- 印刷参数说明
