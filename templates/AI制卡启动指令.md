# AI制卡启动指令｜直接复制

把下面整段交给支持图片/文件读取的 AI，然后上传你的参考图。

```text
我要制作《凡人修仙传》粉丝向收藏小卡。

请先读取本仓库的 skill/SKILL.md，以及其中引用的工程、拼版和QC文档。

我会提供：
1. 卡片主题（角色 / 法宝 / 其他主题）；
2. 一张或多张参考图片；
3. 如有：希望出现的文字。

请严格执行：

【工程】
- 成品63×88 mm；
- 四边3 mm出血；
- 带出血画布69×94 mm；
- 重要主体和文字远离裁切危险区。

【设计】
- 先只做1张黄金正面，不直接批量；
- 保持系列统一的左上/中下文字体系；
- 主体识别优先；
- 可以做二维平面的出框/裸眼3D层次；
- 出框不能破坏主体关键部位；
- 不为了塞文字无限缩小字号。

【素材】
- 不把AI生成图说成官方原画；
- 不确定来源时不要声称“官方授权”；
- 不因为参考图比例不同而拉伸主体。

【流程】
黄金正面 → 统一背面 → 实际尺寸检查 → 我确认PASS → 批量 → A4 2×4双面拼版 → 小样 → QC → PRINT READY。

【修改】
如果只有一张卡有问题，只修改这一张；
已经PASS的卡不要无意义重做。

现在先检查我提供的参考素材，并告诉我它是否适合作为第一张黄金样卡。不要直接生成整套。
```

## 第二阶段：黄金样卡通过以后

复制：

```text
黄金样卡已PASS。冻结当前外框、文字位置、字体层级、背面和工程尺寸。

现在按同一体系批量制作后续卡片，只替换允许变化的主体、名称、对应短文字和必要背景。

每张完成后做最小QC；局部异常局部修复，不重新设计整套。
```

## 第三阶段：准备印刷

复制：

```text
单卡已经冻结。现在读取 docs/A4双面拼版规则.md 和 docs/QC检查清单.md。

生成A4 2×4双面测试拼版。不要猜打印机的长边/短边翻转结果；把第一份定义为TEST，并提醒我先做实体双面小样。

小样确认正背方向、裁切、对位和实际字号后，才能标记PRINT READY。
```
